# Демо-СЭД с бизнес-маршрутами и документами

В проект добавлен базовый слой полноценной системы электронного документооборота (СЭД), который можно поднять на пустой HSQL-базе или применить к существующей базе через update-скрипты.

## Что входит в модель

Модель покрывает ключевые сущности СЭД:

- `SedDocumentType` — справочник типов документов.
- `SedBusinessRoute` — бизнес-маршруты согласования для типов документов.
- `SedRouteStage` — последовательные этапы маршрутов с ролями, SLA и правилом принятия решения.
- `SedDocument` — карточки документов с регистрационным номером, статусом, приоритетом, инициатором, контрагентом, суммой и сроком исполнения.
- `SedDocumentRouteTask` — задачи согласования и исполнения по этапам маршрута.
- `SedDocumentAttachment` — метаданные вложений документов.

## Типы документов в seed-данных

Seed-скрипт создаёт шесть видов документов:

1. Входящее письмо.
2. Исходящее письмо.
3. Договор.
4. Счёт на оплату.
5. Кадровый приказ.
6. Служебная записка.

## Бизнес-маршруты

Для каждого типа документа создан отдельный маршрут:

- `ROUTE_INCOMING_STANDARD` — входящее письмо: регистрация, резолюция, исполнение.
- `ROUTE_OUTGOING_STANDARD` — исходящее письмо: подготовка, правовая проверка, подписание и отправка.
- `ROUTE_CONTRACT_FULL` — договор: инициирование, финансы, юридическая экспертиза, безопасность, финальное подписание.
- `ROUTE_INVOICE_PAYMENT` — счёт: проверка основания, бухгалтерия, казначейство.
- `ROUTE_HR_ORDER` — кадровый приказ: HR, руководитель, ознакомление сотрудника.
- `ROUTE_MEMO_FAST` — служебная записка: автор, руководитель, исполнитель.

## Демонстрационные документы

В seed-данных есть шесть документов в разных жизненных состояниях:

- входящий запрос на коммерческое предложение — на согласовании;
- исходящее письмо клиенту — подписано;
- договор сопровождения — на финансовой и юридической проверке;
- счёт за обслуживание — согласован и ожидает оплаты;
- кадровый приказ о командировке — зарегистрирован;
- служебная записка на доступы подрядчика — требует доработки.

## Где лежат SQL-скрипты

- `modules/core/db/init/hsql/10.create-db.sql` — создание таблиц для пустой базы вместе с остальной схемой приложения.
- `modules/core/db/init/hsql/40.sed-demo-data.sql` — наполнение пустой базы демо-данными СЭД.
- `modules/core/db/update/hsql/26/05/260514-1-createSedTables.sql` — update-скрипт создания таблиц для существующей базы.
- `modules/core/db/update/hsql/26/05/260514-2-seedSedDemoData.sql` — update-скрипт наполнения существующей базы демо-данными.
